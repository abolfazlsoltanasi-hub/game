# 🚀 نئون‌ران | Neon Run

یک بازی آرکید فارسی و لمسی با **Flet و Python**، طراحی‌شده برای موبایل و اندروید.

## 🎮 ویژگی‌ها

- رابط کاربری فارسی با ظاهر نئونی و مناسب صفحهٔ موبایل
- جابه‌جایی سفینه بین پنج مسیر با دکمه‌های بزرگ لمسی
- ۴۵ ثانیه تلاش برای گرفتن بیشترین امتیاز
- ستاره‌ها، امتیاز جایزه برای کمبوی پنج‌تایی، شهاب‌سنگ‌ها و سپر موقت
- سه جان برای هر دور، افزایش تدریجی سرعت و سختی
- مکث و ادامه، صفحهٔ پایان بازی، رکورد و آمار ذخیره‌شده
- گردش‌کار GitHub Actions برای ساخت خودکار APK

## اجرای محلی

Python 3.10 یا بالاتر نصب کن، سپس در ریشهٔ مخزن اجرا کن:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## ساخت APK اندروید

برای ساخت محلی، Java JDK 17 و Android SDK لازم است. سپس:

```bash
python -m pip install -r requirements.txt
flet build apk
```

### ساخت خودکار از GitHub

هر push به شاخهٔ `main`، گردش‌کار **Build Android APK** را اجرا می‌کند. می‌توان آن را از زبانهٔ **Actions** نیز با گزینهٔ **Run workflow** اجرا کرد.

بعد از موفقیت:
1. در GitHub مخزن را باز کن و وارد **Actions** شو.
2. آخرین اجرای موفق **Build Android APK** را باز کن.
3. فایل `neon-run-apk` را از قسمت **Artifacts** دریافت کن.

گردش‌کار APK را می‌سازد و به‌عنوان artifact نگه می‌دارد؛ ساخت APK به‌صورت خودکار پس از commit ممکن است چند دقیقه زمان ببرد و نتیجهٔ نهایی در وضعیت اجرای Actions مشخص می‌شود.
