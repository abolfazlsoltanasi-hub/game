# 🎯 حدس کلمه | Word Guess

نسخهٔ موبایلی و اندرویدی بازی فارسی اصلی شما. گیم‌پلی، بانک واژه‌ها و قواعد بازی در فایل HTML حفظ شده‌اند؛ Flet پوستهٔ اندروید را فراهم می‌کند و بازی را از یک فایل محلی در WebView نمایش می‌دهد.

## طراحی و تجربهٔ کاربری

- صفحهٔ آغازین بازطراحی‌شده با تم آرکید نئونی، کارت‌های ویژگی، رکورد ذخیره‌شده و دکمه‌های واضح
- شروع سریع یک‌نفره در برابر هوش مصنوعی، بدون طی‌کردن دستی مرحلهٔ افزودن بازیکن
- رابط واکنش‌گرا برای موبایل و تبلت، ناحیه‌های لمسی بزرگ‌تر و نشانگرهای واضح در صفحهٔ حدس
- حلقهٔ تایمر، امتیازهای زنده، توقف/ادامه، راهنما، تاریخچه و جدول رکوردها
- انیمیشن‌های سبک، پشتیبانی از کاهش حرکت و نشانهٔ بصری برای فوکوس صفحه‌کلید
- آیکون اختصاصی برنامه و صفحهٔ بارگذاری بومی اندروید
- حالت آفلاین با بانک واژهٔ محلی، به‌علاوهٔ Gemini اختیاری با کلید API شخصی

## ساخت محلی APK

پیش‌نیازها: Python 3.13، Java JDK 17 و ابزارهای Android SDK. Flet در صورت نیاز SDK اندروید را در اولین اجرای ساخت دریافت می‌کند.

```bash
python -m pip install -r requirements.txt pillow
python scripts/generate_icon.py
flet build apk --yes --verbose --python-version 3.13 --build-number 1 --build-version 1.0.1 --output build/apk --android-adaptive-icon-background "#0b0820"
```

فایل APK در پوشهٔ `build/apk` تولید می‌شود.

## ساخت خودکار در GitHub

گردش‌کار `Build Android APK` با هر push به شاخهٔ `main` و نیز به‌صورت دستی اجرا می‌شود. این workflow مستقیماً `flet build apk` را اجرا می‌کند؛ از مرحلهٔ `flet --version --json` در wrapper قبلی که ساخت را متوقف می‌کرد، استفاده نمی‌کند.

1. [وارد GitHub Actions شو](https://github.com/abolfazlsoltanasi-hub/game/actions).
2. اجرای آخر `Build Android APK` را باز کن.
3. اگر اجرا موفق شد، artifact به نام `word-guess-android-apk` را دانلود کن.
4. فایل `word-guess.apk` را روی گوشی اندرویدی نصب کن؛ فایل `.sha256` برای بررسی صحت دانلود است.

اگر ساخت شکست بخورد، workflow گزارش `word-guess-build-logs` را هم بارگذاری می‌کند. فایل APK تنها بعد از کامپایل و بررسی ZIP آن به‌عنوان خروجی موفق منتشر می‌شود.
